## Invalid inputs

No partial world is produced when any error is present.

```text
["frozen","glimmering","hollow"] -> ok=false errors=["unknown_keyword"] warnings=[]
["frozen","frozen","hollow"] -> ok=false errors=["duplicate_keyword"] warnings=[]
["frozen","hollow"] -> ok=false errors=["wrong_keyword_count"] warnings=[]
["frozen",7,"hollow"] -> ok=false errors=["invalid_keyword_type"] warnings=[]
[" Frozen","DROWNED","hollow"] -> ok=true errors=[] warnings=["normalized_keyword","normalized_keyword"]
```
